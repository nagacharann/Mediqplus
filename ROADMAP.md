# Roadmap

Plans change. This file is the public view of direction, and open issues carry the detail.

## Now (foundation)

- [ ] Stable core: patient records, appointments, roles
- [ ] Seed script with synthetic demo data
- [ ] Automated tests for authentication and access control
- [ ] Setup guide that works from a clean machine in under 15 minutes

## Next

- [ ] Audit log for record access and changes
- [ ] Accessibility pass (WCAG 2.2 AA) on core screens
- [ ] Basic reports and CSV export
- [ ] Multilingual UI (English plus at least one Indian language)

## Later

- [ ] AI-assisted workflows for clinic staff (e.g. visit summaries) with clear uncertainty display and human review
- [ ] WhatsApp-based appointment reminders
- [ ] Interoperability exports (e.g. FHIR)
- [ ] Self-host deployment guide (Docker)

## Not planned

- Diagnosis or treatment recommendations presented as medical advice
- Features that require real patient data in public demos
